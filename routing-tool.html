Up and running in 3 steps

No config files and no IP addresses to type. About ten minutes from box to first routed picture.

01

Download & install

Download the installer from GitHub and run it.

02

Connect and open

Plug your laptop into the kit's switch with the CAT-6 cable, then open the app. Devices appear automatically.

03

Route

Select a source, select a display, then pick a layout.

Made for the AVAS-223 demo kit

The app finds these three pieces on its own. Nothing to type in.

AVAS-223 TX

Encoder. Sends the picture from your video source over the network. Appears under Video Sources (TX).

AVAS-223 RX

Decoder. Receives the picture and shows it on your screen. Appears under Target Displays (RX).

MikroTik switch

A pre-configured, lightweight, SDVoE-certified network switch. Plug in and the demo is ready.

Try the layouts

The same six layouts the app offers. Tiles show illustrative sample frames (endoscopy, cath lab, ultrasound, CT), not live video.

Pick a layout

Open Layout on any display. Single View and Off apply right away. MultiView layouts open the Composer.

04

Compose MultiView, then Take

Choose a layout, place sources into blocks, check the staged result, then Take. Nothing changes on the screen until you do.

  • 1Layout, place sources, check
  • 2Staged canvas, marked not on screen yet
  • 3Take sends the staged changes to the display

Built for live rooms

BAVM Console built in

The BlueRiver AV Manager web console opens in its own tab, on the same control server. Both tabs always agree.

Safe staging

MultiView changes stay staged until you press Take. Discard or Clear all if you change your mind.

Copy layout, with Undo

Copy one display's picture onto another in a tap. An Undo toast appears right after.

Dark and light mode

Switch between light and dark from the header, whichever suits the room. A connection status indicator stays in view.

Install guide
  1. Open the GitHub release page using the download button.
  2. Under Assets, download the latest installer.
  3. Run it and follow the prompts.
  4. Open AVAS Routing Tool from the Start menu.
  5. Connect to the kit switch. Devices appear under Video Sources (TX) and Target Displays (RX).
